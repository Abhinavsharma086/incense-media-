# incense-media-

Developed a complete CRM and Lead Management System for Incense Media, featuring Admin and Employee Panels, automated lead assignment, Meta (Facebook & Instagram) Lead API integration, website enquiry management, employee tracking, reminders, lead status updates, and centralized lead monitoring.

## Tech Stack
- **Frontend**: React, Vite, TypeScript, Tailwind CSS, shadcn-ui, Redux Toolkit
- **Backend**: Node.js, Express, TypeScript, Prisma ORM, MySQL
- **Integrations**: Meta Lead Ads Webhook API, Website Enquiry Sync, GST / Invoicing system

## Project Structure
- `/src` - React frontend application with Admin and Employee dashboards
- `/backend` - Express backend API, Prisma schema, services, and controllers
- `/public` - Static assets and icons

## Getting Started

### Frontend
```sh
npm install
npm run dev
```

### Backend
```sh
cd backend
npm install
npx prisma generate
npm run dev
```
